# История изменений

## 1.0.1

Исправления SMART self-test и отчёта.

- исправлен разбор ATA self-test JSON, когда `smartctl` не возвращает поле `passed`;
- числовой ATA status корректно распознаёт успешный тест и `Aborted by host`;
- прерванный ATA self-test теперь корректно отображается как предупреждение;
- результат текущего self-test учитывается в маркере `[НОРМА]`, `[ВНИМАНИЕ]` или `[ОШИБКА]`;
- исправление проверено на реальном формате JSON `smartctl 7.4`, в котором для `Aborted by host` отсутствует поле `passed`.

## 1.0.0

Первый публичный выпуск.

- контроль SMART для ATA и NVMe;
- короткие и длительные самотесты;
- контроль времени выполнения и безопасная остановка запущенного программой зависшего теста;
- Telegram, Matrix и MAX;
- резервное SMS через Huawei HiLink;
- systemd-служба и расписание с последовательным выполнением пересекающихся `Persistent`-заданий;
- ежедневная проверка без лишних уведомлений при исправном состоянии;
- автоматическое определение ATA/NVMe через `kind = "auto"`;
- поддержка `smartctl -d` через параметр `device_type` для USB/SATA-мостов;
- секреты можно вынести в переменные окружения;
- автоматическое разбиение длинных отчётов для Telegram и MAX;
- набор регрессионных тестов.
