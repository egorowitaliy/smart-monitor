# Уведомления

## Когда отправляется сообщение

Режим `check`:

- при нормальном состоянии молчит;
- при проблеме SMART или ошибке проверки отправляет сообщение, если выбран канал уведомлений.

Режим `short`:

- при успешном тесте молчит;
- при проблеме или ошибке отправляет сообщение, если выбран канал уведомлений.

Режим `long`:

- всегда формирует итоговый отчёт и отправляет его, если выбран канал уведомлений.

Если используется `destination = none`, отчёт остаётся в стандартном выводе и журнале, но наружу не отправляется.

Для ручной принудительной отправки используйте `--notify`:

```bash
smart-monitor check all --notify --config /etc/smart-monitor/config.toml
```

## Длинные отчёты

Если полный отчёт не помещается в одно сообщение Telegram или MAX, программа автоматически разбивает его на несколько частей без потери текста. Для MAX части отправляются с небольшой паузой, чтобы не превышать ограничение частоты сообщений в одном чате.

Matrix получает отчёт одним сообщением.

## Несколько каналов

Если выбрано несколько каналов, они рассматриваются как резервирующие друг друга. Достаточно успешной доставки хотя бы в один включённый выбранный канал.

Например, при `all` ошибка Matrix не считается полной потерей уведомления, если сообщение успешно ушло в Telegram или MAX.

Если нужен контроль конкретного канала, запускайте его отдельно:

```bash
smart-monitor check matrix --notify --config /etc/smart-monitor/config.toml
```

## Резервное SMS

SMS через Huawei применяется, когда:

- `sms_fallback.enabled = true`;
- выбран Telegram и/или MAX;
- ни один из выбранных внешних каналов Telegram/MAX не доставил сообщение.

Matrix не участвует в решении о резервном SMS. Его часто используют как локальный канал внутри собственной инфраструктуры.

## Проверка каналов

Telegram:

```bash
smart-monitor check telegram --notify --config /etc/smart-monitor/config.toml
```

Matrix:

```bash
smart-monitor check matrix --notify --config /etc/smart-monitor/config.toml
```

MAX:

```bash
smart-monitor check max --notify --config /etc/smart-monitor/config.toml
```

Все:

```bash
smart-monitor check all --notify --config /etc/smart-monitor/config.toml
```
